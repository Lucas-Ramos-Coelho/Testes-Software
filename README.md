# Página inicial — atividade acadêmica

Página estática pronta para GitHub Pages.

## Personalização

No arquivo `index.html`, substitua as três URLs que começam com `https://seu-usuario.github.io/` pelos links publicados dos seus projetos. Também altere os títulos das atividades e `Seu Nome` no rodapé.

## Publicação no GitHub Pages

1. Crie um repositório no GitHub e envie estes arquivos para a branch `main`.
2. Abra **Settings → Pages** no repositório.
3. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e a pasta `/(root)`.
4. Salve. O GitHub fornecerá a URL pública da página.
